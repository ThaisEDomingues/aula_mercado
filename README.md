# aula_mercado

Sistema de Gerenciamento de Estoque de Mercado 🛒
Este projeto é um desafio de programação em Python focado na manipulação de listas e na criação de um sistema básico de gerenciamento de produtos para um mercado.

🎯 Objetivos do Desafio
O software deve ser capaz de realizar quatro operações principais:

Visualizar Produtos: Listar todos os itens disponíveis no mercado.

Consulta de Informações: Escolher um produto específico para ver detalhes (como o preço).

Adicionar Produtos: Permitir a inserção de novos itens e seus respectivos valores.

Excluir Produtos: Remover itens existentes do sistema de estoque.

📊 Estrutura de Dados Inicial
O sistema utiliza duas listas paralelas para gerenciar as informações:

lista_produtos: Armazena os nomes dos itens (Strings).  

lista_preco: Armazena os valores correspondentes de cada item (Floats).

🛠️ Tecnologias
Python 3.x: Linguagem principal para o desenvolvimento da lógica.

🚀 Próximos Passos Sugeridos
Para concluir o desafio, as seguintes funcionalidades de lógica de programação serão aplicadas:

Laços de Repetição (while ou for): Para manter o menu ativo e listar os produtos.

Estruturas Condicionais (if/elif/else): Para processar a escolha do usuário no menu.

Métodos de Lista: Uso de .append() para adicionar e .pop() ou .remove() para excluir itens.

Este projeto demonstra a aplicação de pensamento computacional e lógica de programação voltada para ferramentas de produtividade.
